WINSCORE v5.01 by Leland Smith
==============================


Introduction
============

This package contains a full version of WINSCORE with the latest program, library, symbol list, and help file updates Smith added to his website before his death in 2013, after which it became abandonware. Similar to the version of SCORE version 4 for DOS also available here on the Internet Archive (https://archive.org/details/score_202308), this version was assembled using files left available on the internet including archives of Smith's website.


Requirements
============

* 30 MB free space
* Windows 98 or later (through Windows 10) (also works in a virtual machine and Wine)
* Adobe Type Basics (optional)


Installation Instructions
=========================

Copy the winscore folder to C:\ or C:\Program Files\. The program has hard-coded path expectations for its location. Do not place it in C:\Program Files (x86)\ even though it is a 32-bit program. You can make a shortcut to WScore.exe on the desktop or wherever you wish. 

In order to view accurate fonts within WINSCORE, WINSCORE expects the requisite PostScript fonts to be installed in C:\PSFONTS. The Adobe Type Basics library provides these, and it can be found at https://macintoshgarden.org/apps/adobe-type-basics. The Adobe Type Manager program is not required.

To install additional PostScript fonts place the PFB file in C:\PSFONTS and the PFM file (if present) in C:\PSFONTS\PFM. You can use FontForge (fontforge.org) to convert modern TrueType fonts to PostScript fonts for use with WINSCORE.
