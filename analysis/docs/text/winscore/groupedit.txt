A
(group alter) (type A)

 After you indicate an area on the
 screen, you will be asked for a code number (e.g. 1 for notes, 2 for rests,
 etc.) Then you will be asked, "Type P#, chng, P#, chng, P#, chng
 ...." Here you should type pairs of numbers indicating the
 parameter and the change desired. For example, to change a group of notes to
 eighth notes you would type "7 .5 9 1." (P7 = .5 = eighth
 note time value, P9 = 1 = add a single flag to each note stem.) In some
 cases it may be more efficient to use the conditional
 editing method for this kind of editing.

 Height
of page 

 Type H or HS
 or click on one of the buttons. SCORE will display the current height of the file, and
 prompt for a new height. H finds the total height of all the material
 on the page. HS finds the height from the bottom line of the lowest
 staff to the top line of the highest staff. 

 Type a number to indicate the new height and type the number of staves in a system. (include any unused staves. )

SCORE asks how many staves are in each system from the bottom up. If every system has the same number of staves, you may specify a single number for this prompt. The
 H command will put more space between each system (if you are adding height to the file) or remove space from between the systems (if you are reducing the height). If you want to add space between every staff, type 1 regardless of how many staves are in a system.

Note that the H adjustment is not intelligent, like VJ. It blindly closes up or adds space between the staves equally, regardless of the music. As a general rule, we recommend using the
 VJ command to bring the staves as close together as possible and
 then use the H command to add space where desired.

 You may avoid
the dialog box by typing on a single line H
or HS followed by the new height and
the staff group numbers. 
H 10 2 2 3 2 would set the height to 10 inches, with staff groups of 2,
2, 3 and 2. 
H 7 alone would set the height to 7 inches, with the staff
group number defaulting to 1. 

VJ vertical justification
 
(type VJ)

This command is used
to avoid vertical collisions between Items found on different staves.

Type VJ
or click on the VJ button. The following dialog box will appear. 

You may press <ENTER> to accept the defaults, or type different values in
the various boxes.

In this case the
bottom staff number was given as 3, the number of staves to process, 2.

After invoking VJ, SCORE searches through the file for items that extend above and below the staves. Assuming you accepted the default settings
for Minimum vertical space = 4, and Minimum horizontal space = 4, VJ would make sure that any items within four horizontal spaces of each other would have a minimum vertical distance of four scale steps between them. To create this distance,
 VJ alters P4 of the upper staves (Code 8) indicated. If you want less
vertical space between staves, make the first number smaller. In general, we have found the default settings of 4,4 to work quite well.
(Also be sure to read the section on the H
[total page height] command.)

Note that the VJ command is ideal for creating an orchestral score that employs
"french scoring." If you input your orchestral score on a standard template (with the same number of staves on each page) and later decide to remove the blank staves (when an instrument rests), the
 VJ command will quickly allow you to close up the extra space on the page. VJ does not require staff numbers to be continuous
(i.e., you may have staff no. 4, then staff no. 6, etc.). VJ will correctly justify the height of the file in a quick and efficient manner.

 You may avoid
the VJ dialog box by typing on a single line VJ
followed by the proper numbers; n1, n2, n3, n4, n5, as they would appear
in the dialog box. N1=minimum vertical space, n2=minimum
horizontal space, n3=minimum space between staves, n4=bottom staff
to consider, n5=number of staves. If only n1 is given, the other numbers
will take the default values of 4, 12, 1, 200. 
VJ 4 would perform the vertical justification with the default values.

Measure
Numbers 

 (type MN)

The affect of most of the check boxes should be
self-evident.

For <Repeat 1st ending bars numbers>, if
unchecked, the numbers remain in sequence.

If this box is checked, the following numbering would
occur. The 2nd ending will include the same measure numbers as the 1st ending.

If the <Continue numbers> box is checked, the
next time MN is used, the <First measure number> box will be updated to
one higher than the last measure on the previous page.

It is likely that some editing of the height position
of the numbers will be necessary.

An external macro
file may be created to set measure numbers. The required syntax is MN followed
by seven numbers, N1, N2, N3, N4, N5, N6, N7. N1 = 1st measure number. N2 sets
the frequency of the numbers. N2 = 0 puts numbers only at the front of each
line. N2 = 1 puts numbers on all bars. N2 = 4 puts numbers on every 4th bar, = 5
puts numbers on every 5th bar, = 10 puts numbers on every 10th bar. If N3 is set
to 1, the first bar of music will be considered as a "pickup" and the
numbering will begin on the second bar. N4 sets at which bar the first number
will appear. If N5 = 0 the numbering will continuing through 1st and 2nd
endings. If N5 = 1, the numbers under the 1st ending will be repeated under the
2nd ending. If N6 = 1, no number will appear on the first bar of the music. If
N7 = 1, the last number on the page will be retained and the next page processed
will begin with the next bar number. Note the following example:

MN 1 1 0 1 1 0 1

This syntax must be
strictly followed.

See section on reading
external macro command files for further use of MN.

SEP -
Separate two-voice extracted orchestral parts.

Orchestral
scores often combine two parts, such as 1st and 2nd clarinets, on one staff.
Whereas the players' parts usually include only the music for one instrument.
After the part extraction (PARTS) feature is used, the
individual player's part is usually extracted from the double part. The SEP
command does this operation.

SEP
will process grace notes (where P7 = 64 or 65) but SEP will ignore cue notes
(where P4 is greater than +/-100.)

When
you have on the screen a page of double-part music and you type SEP,
the following dialogue box appears. If you want to process only part of the
page, type in the appropriate staff numbers. Be sure to save the results
to a new name, because you will want to return to the original page to extract
the other part. Some touch-up editing is usually necessary -- this is especially
true in regard to slurs and ties. The placement of these items in a double part
is often different from what is required for a single part. While the program
will often move the slurs, etc., to their proper positions, sometimes it may be
best to leave all these items in their original positions. Then you can easily
delete which items are not needed and edit the others to their proper positions
and shapes. In this case you should check the "Keep all slurs" box.

If
you wish to bypass the dialogue box, you can type all the command elements on
one line. To get the same results as you would from the above dialogue box,
type:

 SEP
2 1 0 200 10 

(Separate 
voice 2, starting on staff 1,
positions 1 to 200,
up through staff 10)

If
you add one more number ( "1"), the output will keep all slurs.
