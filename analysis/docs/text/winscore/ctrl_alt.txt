Using the <ctrl> and <alt> shortcut keys

Following
shows the various keyboard shortcut commands available with the <ctrl> and
<alt> keys.
Equivalent
typed commands are green.

 ******
The following only apply when NOT in Edit Mode ****** ***********
<ctrl> *********** <ctrl>O --
open a file. (G 
= get a file.)<ctrl>S --
"Save " a file. (SM = save the
file with the same name.)<ctrl>F --
get the last file read in the previous session. (LAST)<ctrl>P --
go to PRINT menu. (PR) <ctrl>H --
view and alter the page height. (H) <ctrl>C --
indicate an area to copy. (C)<ctrl>M --
indicate an area to move. (M)<ctrl>D --
indicate an area to delete. (DE) <ctrl>L --
indicate an area to line up and justify. (LJ)<ctrl>J --
indicate an area to justify. (J) <ctrl>X --
indicate an area to cut (copy.) (CT)<ctrl>V --
indicate an area to paste the cut material. (PST) <ctrl>T --
indicate an area to transpose. (TR) <ctrl>Z --
undo the previous group edit command. (UNDO)<ctrl>A --
redo the action that was undone by "undo." (REDO) <ctrl>U --
undelete - restore the last deleted item. (UND) <ctrl>R --
restore an item that was inadvertently lost due to edit changes. (RESTO) <ctrl>E --
remove/restore parameter boxes. (E)

 <ctrl>0 --
bring up Path List dialog box.<ctrl>1
. . . . <ctrl>9 --
activate path from Path List. 

 <ctrl><home>

<ctrl><Page
Up> -- increase the image size (Zoom).

<ctrl><Page

 ZOOM
while in EDIT MODE

You may zoom (enlarge the
display) in or out with the following commands:

<ctrl><Page Up> = zoom up 12.5
%
 <ctrl><Page
Down> = zoom down 12.5 %

 <ctrl>2
= zoom to 200 %

 <ctrl>3
= zoom to 300 %

If either of the last two
above is repeated, the display zooms back to 100 %. 

Also if the screen image
is larger than the physical screen size, it may be moved by holding the 
<ctrl> key while hitting any of the arrow keys. This does the same thing
as sliding the scroll bars by means of the mouse. (Some people like to use the
mouse as little as possible.)

 See
also <alt>n, where n is a parameter number.
