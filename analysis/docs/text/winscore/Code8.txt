P2 Staff lines are
numbered from the bottom of the page upward. The default staff positions, at
size 1, put 10 scale steps between the staves. Every Item
is attached to some Staff number. The Staff numbers range from 0 to 256, however
staves 201 to 256 are reserved for an added page offset to the right (RECTO
position).

Typing STA n will create a staff at the P2 =
n vertical position.

P3 Left end position
of staff. P3 can equal from -20 to 220. The default position is 0.

P4 The staff may be moved up or down from its "normal" position by putting a value in P4. All P4 values are figured in scale steps based on the size factor given in P5. In general, P4 of the the bottom staff (P2 = 1) should remain at
zero. 

P5 sets the size of the space between staff lines. Each space is made up of 2 "scale steps." P5 controls the basic size of all items connected to the given staff (same P2 number). The default vertical size of the staff is .35 inches (8.89mm). If a 1/2 inch staff is desired, P5 should be set to 1.429, etc.

Setting P14 to a value, in
centimeters, will automatically set the proper value in P5. 

 For example, if P14
= .78, P5 will become .877, creating a staff height of .78 cm.

This
presumes you will be printing the page at size 1.

P6 Right end
position of staff. P6 can equal from -20 to 220. The default position is 200.
(P6 = 0 = 200).

P7 may be used to create staves with other than 5 lines. For a six-line, staff, 
P7 = 6; for a three-line staff, P7 = 3, etc. The bottom line of the non-standard staff will be in the same position as that of a regular staff, unless a three-digit number
(XYZ) is used. In this case, the left digit
(X) tells which line of a normal staff will be the new bottom line.
 YZ then holds the number of staff lines to appear.

 P7 = -1 = the staff is invisible. This can be useful in many ways.
The staff will appear in light gray on the display, but will not print. Typing
INVIS when out of edit mode will make it disappear/reappear.

P9 = instrument identification number. This is used for extracting individual parts from an orchestral score.

P10 = distance, in inches, for placement of staff above normal position of staff 1. When P10 is used, P4 is ignored. (However, for staff 1 itself, it is best to leave both P4 and P10 at 0.)

P11 = staff line thickness. (ON PostScript PRINTER ONLY)

The default thickness of staff lines will normally depend on the thickness number given when using the Print command. However, for staff sizes (in P5) less than .65, the line thickness will be decreased by 1 pixel. A value in P11 will add or subtract pixels from the given Print line thickness, regardless of what the staff size is.

 **** The default thickness of a note's ledger lines will usually be

 **** related to the thickness of the staff lines. (See Code 1 help.)

 **** If the staff's P11 is set to 99, then the staff lines AND the

 **** ledger lines will all be the thickness given in the Print command.

 **** However, if a note has a value in its P16, this will override the

 **** the staff's P11. .

P12 While P12 = 0, the number of the staff will appear at the far left side of the screen as a guide to editing. This number will NEVER appear in the printed music. If P12 is set to 1, this number will not appear on the screen.
Typing NMO will turn this feature Off/On.

P13 
= number of 1/2 steps to transpose when playing MIDI output sound. If this parameter is set,
the transposition number in the PLAY menu need not be set. For example, if you
have a staff for Horns in Eb, you would set P13 to -9; for Clarinets in A,
P13=-3; for Trumpet in D, P13=2; etc.

P14
can be used to set the staff size in centimeters. See details in
P5.

 P25 layer number. 
See Color Control.

 P26 color/gray
value. 
See Color Control.
