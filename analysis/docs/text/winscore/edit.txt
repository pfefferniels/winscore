Editing the Music

The simplest way to enter Edit Mode is to point the cursor at a note or other item and click the left mouse button. When this is done the indicated item will turn red.
See the section on mouse usage for more information. Below are listed the typed commands to enter Edit Mode: 

I n -- where n is any item number. (I = Item)

 If no number is given, n will be assumed to be the last item edited or entered on the page. Hitting <Enter> will step on
to the next item. Typing X or clicking with the right mouse button or clicking on the
X box in the bottom toolbar will terminate Edit Mode in all cases.

Typing II
 will edit the object with highest Item number. 

 ST x n1, n2, n3 -- where x is any Staff number and n1, n2, n3 are any Code numbers. (ST = Staff)

 Editing will begin with the first item with any of the Code numbers n1, n2, or n3 found on Staff x. Hitting
 <Enter> will step through all items with those same Code numbers found on that Staff. If
 x is greater
 then 256, then all
 staves are searched for the given code numbers. If a staff number is given
 but no code numbers are given, then all code numbers on that staff may be
 edited.

 Add 1000
 to x to edit on
 all staves up from staff x.

Example: ST 1008 3 17

This will look at all Code 3 and Code 17 

items found on staff 8 and above.

 If 
 ST 
 alone is typed, the last
 item edited or entered will determine the staff number and Code number for
 editing.

 STX n1, n2, n3. 

 Editing will begin with the first item with any of the Code numbers n1, n2, or n3 found on
 the lowest Staff. Hitting <Enter> will step through all items with those same Code numbers found on the entire page. 

 ED
pos, x, n1, n2, n3 

 This allows you
 to edit at position pos, staff x, up to 3 different code numbers.
 A vertical line of dots will appear at the position given and all items within 5 spaces of the line on that staff will come
 up for editing. To pass over an item type <enter>. 

 If 1000 is added to
 x, editing will begin on staff x and continue on up. If code numbers are given, the item
 nearest the line with that number will come up. Following that, all other items with that code number near the vertical
 line will come up for editing.

 Example: ED 70 1008 3 17

 This will look at all Code 3 and Code 17 items

 found near position 70 on staff 8 and above.

 Typing ED alone,
 or with pos as zero, assumes the
 position of the last item edited or entered. If the staff number x = 0, items on all staves
 are considered. If n1 = 0, or omitted,
 all Code numbers are considered.

 Commands while in Edit Mode

 Changing
Parameters by Number

 All SCORE Items are stored in a list of parameters. The location and appearance of any item is changed when the proper
parameter values are changed. When any Item is in Edit Mode, its current parameter list will appear at the top of the screen.
Parameters are changed by typing pairs of numbers: p v, where
p is the parameter to be changed and v
 is the new value to be entered. Several pairs of numbers may be typed on a single line.

 Typing -p
 alone will change the sign of parameter p. 
 i.e. If P7 = 3.46, typing -7 will cause P7 = -3.46. Typing -7 again will
 change it back to positive.

 While editing, the
 values of parameters 1 through 20 will appear in boxes at the top of the
 screen. To see values of parameters 21 through 30, type PM.
 If you have made several changes to a parameter, you may see its original
 value by typing PM n,
 where n is the parameter number involved. The lower boxes will show the
 current values and the upper boxes will show the original values. 

 Relative
Parameter Changes

The process described above involves absolute parameter
changes. Relative changes are made by adding
 two zeros to the parameter number (the
first number of a pair). Thus, typing 600 5 causes 5 to be
 added to the original value in P6. (This is equivalent to the programming statement, P6 = P6 + 5.)

Typing /6 5 is the same as typing 600
5.

Parameter Transfer

Adding four zeros to the parameter number (the
first number of a pair) causes the parameter to pick up the value in the parameter indicated by the second
number of the pair. Typing 50000 4 causes the current value of P4 to be put into P5. (This
is the same as saying P5 = P4.)

Typing //5 4 is the same as typing 50000
4.

buttons:

 Special
Editing With <alt>Parameter n

When
in Edit Mode, typing <alt>n (n = any
parameter number, hold both keys

 down at once) will allow you to increase or decrease the value of that parameter by
 tapping on the up arrow or down
arrow cursor keys.
 The
increment value for the arrow keys is originally set to 1. The increment may
 be
reset at any time by typing INC followed by
 a number.
The parameter number and increment will appear in a box in the upper left
 area
of the screen. This value will determine
 the
action of all editing with the arrow keys.

 When
using the <alt>n feature the increment may
 also be changed by hitting the left
 arrow key or the right arrow key.
 
 This will change the increment by + or
 - 0.1.

 To
regain the normal function of the arrow keys, type <alt>X.

 Special method to clear many parameters at once:

Type a -9999 b, where a is the
first parameter to be

 set to zero and b is the last parameter. For example,

 7 -9999 12 would set all the parameters 7 through 12

to zero at once. If b
is omitted, all parameters from 

a up will be zeroed.

 Canceling
Edit Changes

 At
 any time
 after you have made changes to an Item and
 before you move on to another Item or exit from Edit Mode, you may cancel
 the changes by typing AB
 or <ctrl>B or clicking on the 
 (abort) box. If you type 
 ABX, all changes
 will be cancelled and the program will exit edit mode. 

 Deleting
an Item

 To
delete an Item hit the <Delete> key, click on the DEL button, or type DE.
After the Item is deleted, the next Item in order, either forward or backward, will come into Edit Mode.

 Hitting
 either F11 or F12, or clicking on these buttons, ,
 will delete the Item and move back or forward to the next Item with the same
 Code number.

 You can recover from
 an erroneous deletion by typing "UND" or clicking on the undelete
 button, . 

Ending
the Edit

 Type
 <esc>, X, or click on the X button, or click with
the right mouse button to exit from any form of edit mode. If you type X

n, item number n comes into Edit Mode.

Clicking on these buttons, ,
will end the edit and move back or forward to the next item.

 Clicking
on these buttons, , will
end the edit and move back or forward to the next item with the same
code number. Typing BZ or NZ will do the same thing.

 If
 you type XX,
 the edit will end in the normal way and the edited item will be saved in the
 !!CUT0.TMP file. This item may be retrieved at a later date with the PST0
 command.

 Typing
<Enter> will end the edit and move on the the next item.

 If
 after exiting from Edit you realize you meant to type C
 (copy) instead of X, you may retain the
 edited Item and restore its original form by clicking on the restore box. 

 Copy
and Exit

 When
you move an Item in Edit Mode, the original form remains in place. If you exit
from Edit Mode the original disappears. However typing C
or clicking on the COPY button will consider the Item in the new position as a
copy, exiting from Edit Mode. The original Item will remain in place. 

 Typing
CC (copy, continue) or clicking on the CC
button will conclude the copy but continue with the new Item in Edit Mode.
Typing CX or clicking on the CX button will
conclude the copy and move to the next Item in order after the original Item. Clicking
 the middle mouse button is the same as typing CC.

 ZOOM
while in EDIT MODE

You may zoom (enlarge the
display) in or out with the following commands:

<ctrl><Page Up> = zoom up 12.5
%
 <ctrl><Page
Down> = zoom down 12.5 %

 <ctrl>2
= zoom to 200 %

 <ctrl>3
= zoom to 300 %

If either of the last two
above is repeated, the display zooms back to 100 %. 

Also if the screen image
is larger than the physical screen size, it may be moved by holding the 
<ctrl> key while hitting any of the arrow keys. This does the same thing
as sliding the scroll bars by means of the mouse. (Some people like to use the
mouse as little as possible.)
