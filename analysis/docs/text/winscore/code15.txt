EPS (Encapsulated
PostScript) files created by SCORE may be combined and manipulated in many
ways by the use of Code 15. The graphics in the following example were used to
create an EPS file to demonstrate the method of using this feature. First
type 15 a b c, where a is a staff number, b is the horizontal position, and c is
the vertical position.The
program will prompt you for a file name. The EPS extension need not be typed,
however it is advisable to give the complete path. (E.g. C:\MUS\PICTURE.EPS)A
rectangle indicating the bounding box limits of the graphics will appear.This
box may be moved, scaled or rotated using the normal editing commands. 
 Then
a copy of the box was moved 180 steps to the right and the horizontal size
parameter, P5, was set to -1 to create a reverse image. Other
items were added; Code 9 items and text. The
result, when printed, appears as below. This
then may be used to create a new EPS file. Below, three copies of the new file
are juxtaposed in various ways. P12
is used to rotate the image by degrees. In the following, two
copies of the EPS file are used. The first has P12 set to
-135 and the second has P12 set to 45. 

 If P13 is set to 1, a new PostScript file name will be requested.
 If no specific path is given, the user's current directory will be searched.
 If the the file is not found, then \WinScore\Scorlib\ will be searched, If the
 file is in some other location, the complete path must be typed.
