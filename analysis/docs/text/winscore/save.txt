Saved File Structure

 SCORE files are normally saved with the extension .MUS, however any extension may be used. The files are saved in binary format where the first word is the word count for the entire file.The word count is normally a 16-bit integer, however if the word count exceeds about 31000, then a 32-bit integer is used. Saved files with less than 31000 words can be read back into the earlier (DOS) versions of SCORE, except, of course, any new features of WinScore will be ignored. Files with greater than 31000 words cannot be read by the earlier versions of SCORE. The files are concluded with a 6-word trailer. The last word is -9999. The next word back is the count of the preceding trailer words (currently 5). The next word back is the measurement code (0 = inches, 1 = metric). The next back is the
program version number. The next is the program serial number (a converted integer). The first word of the trailer is currently undefined.
