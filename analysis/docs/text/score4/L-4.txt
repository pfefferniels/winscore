

"L", "LJ" command = line up multi-voice music.

The prompts for this feature are similar to those for the Justify command.

The L command may be used when there is more than one voice on a single
staff and also for systems involving up to 16 staves.  For this to work
properly the individual voices must all have exactly the same number of
beats.  Watch the typeouts to see if there are any errors in this regard.
This Lineup command  assumes that the first note and the last barline
on the lowest staff are properly placed.  It is often necessary to rejustify
the music after it has been lined up.  For this purpose "LJ" combines the
features of "L" and "J".

(The Lineup command creates a kind of proportional spacing which allows
less room for a free standing whole note than 4 quarter notes require, etc.)


LIN = puts up horizontal line.
LOG = SCORE logo.
