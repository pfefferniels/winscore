P5 = 99 = common time (C)
   = 98 = alla breve  (¢)
   =  0 = single meter number (found in P6) centered

*
                                                                            2/2
Use P8 and P9 for double meters (e.g. 3/4+5/8).

P10 alters the position of the "+" between double meters.

P11 alters the distance between the meters.

P12 = 1 = suppress the "+" between double meters.

P13 = change type font by entering font number + 1000. (1004=Helvetica, etc.)

P14 = 1 = lineup and justify will ignore this time signature. ( 0 = normal )

P15 = horizontal offset from P3 position.  (Lineup/Justify will ignore item.)

P16 = laser thickness. For small staff sizes, negative values make lighter
                       face meter numbers with conventional music font.

  ****************************
  CM = CenterMeter (& numbers).  This sets P3 and P15 to center meter over a
  ****************************   nearby bar line. (But not with double meters.)
                                       (P9 = -1 does same as CM)
