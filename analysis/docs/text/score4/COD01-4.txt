For grace notes (mini-notes) add 100 to P4  (or -100 if P4 is negative.)
Add 100 to P8 to slash the grace note's tail.  (-100 if P8 is negative.)

                                                                          2/13

P5 is normally a 2-digit number which does double duty.

  The left digit tells which direction the stem will go.  
     1 = stem up, 2 = stem down.
          If there is no left digit the note will have no stem.

     The right hand digit indicates the note's accidental.
        
        0= none     3= natural        6= 1/4 tone flat   8= 1/4 tone sharp
        1= flat     4= double flat    7= 3/4 tone flat   9= 3/4 tone sharp
        2= sharp    5= double sharp

     P5= 13 = stem up, natural sign on note;  = 21 = stem down, flat on note.

>>>P5 Shortcut: FLT = flat; SHP = sharp; NAT = natural; NAC = no accidental.
     Type any of these 3-letter codes to make appropriate change to P5.

    ****** Type FLIp to flip the note's stem to the opposite direction.

 Add 100 to P5 to put parentheses around the accidental.


*
                                                                          3/13
  Accidentals are displaced to the LEFT by adding numbers to the right of
  P5's decimal point.  The program multiplies this number by 10 to get the
  actual displacement. If the 1st digit after the decimal point is 9, the
  remaining digits X 10 gives the displacement to the RIGHT.
     
     P5 = 12.25 = stem up, sharp displaced 2.5 steps to LEFT of normal.
     P5 = 12.935 = stem up, sharp displaced .35 steps to RIGHT of normal.

ENHarmonic changes: Type ENH n, where n = 1 or -1. If n=1, the note moves UP
     1 step and a sharp is changed to a flat. If n=-1, the note moves DOWN 1
     step and a flat is changed to a sharp, etc. If NO number is given, the
     proper change is assumed. (ENH does NOT consider key signatures or
     previous accidentals.) See Version 3.1 Manual Additions for details.

P6 = note head types.  P6= 0= black, 1= half, 2= whole, 3= breve (dbl. whole)
                       =4= white diamond,   5= black diamond, 6= X note
                       =7(or -1)= headless, 8= diamond/x,     9= oval/x

        Add 10 to P6 to put these note heads in parentheses.

 *********** Any Library item may be used as a note head.   *****************
 *********** Use the Code-9 P5 value as the note's P6 value.*****************

*
                                                                          4/13


P7 holds rhythmic time value (ALWAYS needed for automatic spacing systems).

   For a normal quarter note P7=1; for an eighth, P7=.5; for a half, P7=2;
   for a whole note, P7=4 (i.e. 4 times as long as a quarter note).
   An eighth note triplet = .3333, or 1/3 of the time of a quarter.

   Negative values in P7 are used for special situations.

       P7 = -1 = ignore note when justifying.
            -2 = suppress printing of ledger lines no matter what vert. pos.
            -3 = do both of the above.


P8 holds stem length information.  P8 = 0 = normal stem (1 octave up or down).
   Positive values in P8 extend the stem.  P8 = 1.5 = stem is 1.5 scale steps
   longer than normal.  Negative values shorten the stem.  P8 + or - 100 puts
   slash on grace note tails. (i.e. P8 = -101 = slashed note w/ shorter stem)




*
                                                                          5/13
P9 can be a 2-digit number, with the left digit indicating the number of DOTS
   which are to follow the note, and the right digit indicating the number of
   TAILS (flags) to be added to the stem.  Numbers to the right of P9's decimal
   point will cause the dot(s) to be displaced to the right.  The program
   multiplies this part of P9 by 10 to get the displacement value.  If the 
   1st digit after the decimal point is 9, the remaining digits X 10 gives 
   the displacement to the LEFT.
     
     P9 = 12 = note with 1 dot and 2 tails.
     P9 = 20.31 = note with 2 dots displaced to right by 3.1 units, no tails.
     P9 = 10.94 = note with 1 dot displaced to LEFT by .4, no tails.

   When 100 is added to P9 the dot following a note which appears ON a staff
   line will appear below that line instead of in the normal position above
   the line.  Adding 1000 to P9 displaces dots one note width to the right.

P10 is used to displace the note head from its normal position (given in P3).
    This is usually used for chord structures which include the close interval
    of the second.  If P10 = exactly 10, the note is displaced 1 note width to
    the right.  If P10 = exactly 20, the displacement is 1 note width to the
    left.  Any other numbers will displace the note in terms of horizontal
    space units.

*
                                                                          6/13
P11 holds information about the marks which are often attached to note heads.
     [See below re. mark displacement (P13, P14) and mark size (P18).]

 1 = musica ficta flat     13 = harmonic (o)         25 = accent-tenuto
 2 =   "      "   sharp    14 = fermata              26 = double stac. ..
 3 =   "      "   natural  15 = arsis sign           27 = triple  "    ...
 4 = wedge                 16 = thesis sign          28 = quad.   "    ....
 5 = accent                17 = mordant              29 =
 6 = tenuto (dash)         18 = inverted mordant     30 = fingering 0
 7 = staccato              19 = heavy wedge          31 =     "     1
 8 = wedge-staccato        20 = trill                32 =     "     2
 9 = accent-staccato       21 =   "   with flat      33 =     "     3
10 = tenuto-staccato       22 =   "     "  sharp     34 =     "     4
11 = down bow              23 =   "     "  natural   35 =     "     5
12 = up bow                24 = plus (+)             36 =     "     6

  Other marks may be positioned near notes using Code 9 or Code 11.

P11 = 99 makes heavy line extending to right of note head.
       P13 sets how many steps to start of heavy line. (P13 default = 2.3)
       P14 sets total distance from front edge of note to end of heavy line.
             (P14 default = 10.)

*
                                                                          7/13
  
  Normally, most marks appear on the note-head side of the note-stem
  combination.  For these marks the use of a negative value in P11 will
  force the mark to appear on the stem side, regardless of the stem direction
  as set in P5.

        P5 = 10, P11 = 32 = stem up, fingering number 2 below note head.
        P5 = 10, P11 = -32 = stem up, number 2 above note's stem.

  Numbers to the right of P11's decimal point will cause the mark to be
  displaced vertically.  The program multiplies this part of P11 by 10 to
  get the displacement value in scale steps. (P14 may also be used for this.)

       P11 = 5.13 = accent over note, displaced by 1.3 scale steps.
       P5 = 20, P11 = -34.2 = stem down, fingering number 4 pushed 2 steps
                               below end of note stem.

P12 may be used to place note on staff above (P12=1) or staff below (P12=2)
    the staff to which the note is actually attached.
         P4= 4, P12= 1 = note appears in bottom space of staff above.



*
                                                                          8/13

P13 may be used to displace marks horizontally (+/-) from their default pos.
    If P13 = 99, the mark will be centered on the note stem.
         (P13 = 99 and p11 = 7 centers staccato dot over stem.)

P14 may be used to displace marks vertically (+/-). (by scale steps.)

P15 is a general note size factor. ( i.e. 0.75 in P15 will create a note
              that is 75% of the normal size for a particular staff size.)

P16 controls the thickness of ledger lines (ON LASER PRINTERS ONLY.)
      The default situation is that ledger lines will be 2 pixels thicker
      than staff lines.  (Staff line thickness depends on the basic line
      thickness given when using the PRint command.  However the thickness of
      staff lines can also be influenced by a staff's P11.  See Code 8 help.)
      Mini-notes (P4>100) will normally have only one pixel added to ledger
      line thickness.
   The value in P16 will add or subtract from the line thickness given with
   the PRint command, WITHOUT REGARD to staff line thickness.  If P16 = 99
   then the note's ledger lines will be exactly the same thickness as the
   staff lines.  (This is for very small staff sizes.)
   If P16 is not zero, all defaults are overridden.

*
                                                                          9/13

P17 = extension of SOURCE of note stem - in + or - scale steps from P4 pos.
           Add 100s for thicker stems -- 100=add 1 pixel, 200=add 2, etc.

P18 = change size of marks(P11) from default.

------- Letter Commands while editing Notes -------------------------------

>>> Stems  (P8)
 ADJ   = adjust note stem to beam.
 ADJX  = adjust note stem when beam's stem direction is opposite.
 ADF   = adjust note stem to beam (F = in the French manner).
 ADFX  = adjust note stem when beam's stem direction is opposite.
 FLI   = flip the stem direction.
 NST   = no stem on note. (removes left digit of P5)
 STM   = (stem -) shorten the note stem by 1/2 scale step. (P8)
 STP   = (stem +) lengthen the note stem by 1/2 scale step. (P8)
 STN   = set stem length to normal. (P8 = 0 = 1 octave)



*
                                                                         10/13

>>> Rhythm
 CH    = apply rhythm of note with stem to all chord notes.
                If CH is typed it may be followed by a P7 duration value.
                (e.g. 'CH .25' will make all chord notes have 1/16 rhythm.)
 CUE   = make note cue size. (P4 + 100)
 CUX   = normal size note.  (P4 < 100)
 RH64  = 64th note. (P6, 7, 9)
 RH32  = 32nd note. (P6, 7, 9)
 RHD   = makes double whole note. (P6, 7).
 RHS   = makes 1/16 note. (P6, 7).
 RHQ   = makes 1/4 note. (P6, 7).
 RHH   = makes 1/2 note. (P6, 7).
 RHW   = makes whole note. (P6, 7).
 RHG   = makes grace note. (P4, 7, 8, 9)
 RHU   = change rhythm to quintuplet. (P7)
                    e.g. P7=.5 (1/8) becomes =.4 (1/10)
 TRP   = change rhythm to triplet. (P7)
                    e.g. P7=.5 (1/8) becomes =.333 (1/12)
                TRP and RHU are ignored if original rhythm is not
                a basic duple value. (1/2, 1/4, 1/8, etc.)

                                                                         11/13

 ADT   = add tail(s). (P9)  No change in rhythmic value.
 NTA   = remove tail(s). (P9)  No change in rhythmic value.

>>> Dots  (P9)
 DOT   = adds dot to note - changes P7, 9.
 DDT   = make double dot. (P7, 9)
 DUD   = dot up/down, above or below staff line. 
 SPD   = space dot to right
 SPD-  = space dot to left
 SPDN  = space dot to right 1 note width


>>> Offsets
 OFL   = offset one note width to the left (P10=20)
 OFR   = offset one note width to the right (P10=10)
 OFM   = offset minus, moves note .5 step to left. (P10)
 OFP   = offset plus, moves note .5 step to right.
 NOF   = no offset of note - P10 = 0.

                                                                         12/13

>>> Accidentals  (P5)
 DBF   = adds double flat to note.
 DBS   = adds double sharp to note.
 ENH-1 = move note down 1 step and change accidental to
                                enharmonic equivalent (if possible).
 ENH+1 = move note up 1 step and change accidental to
                                enharmonic equivalent (if possible).
 FLT   = adds flat to note.
 NAC   = no accidental - removes any accidental from note.
 NAT   = adds natural to note.
 SHP   = adds sharp to note.

 ASP   = automatic spacing of 2nd accidental in chord.
 NOS   = no extra space for accidental.
 SPA   = space accidental to left
 SPA-  = space accidental to right
