                                                                          1/5
SA name = save data in file called "name."
   If the file already exists you will be asked if you want to write over it.
   If the file name uses the current extension it need not be typed.
   If an extension or dot is not typed, the current extension will be used.

SM = save data with the SaMe name as last used.
     This is the usual, quick way to save edited files, but no overwrite
     warning is given.  Always be careful when saving files with "SM".

SNX = save a file with the NeXt name alphabetically from the last file saved.


SC n = put up the spacing scale above staff number n.
SCX = erase the spacing scale.

SH = show certain items with their actual type fonts.
     After this, a Z must be typed to recompute the screen data.

SHX = turns off the display of the actual type fonts.  (This is the 
      default situation because there are many fewer vectors to compute.)
      After this, a Z must be typed to recompute the screen data.

                                                                          2/5
SEP = Group edit command to assist in seperating parts from multi-part staves.

SP n = set staff n to be basis for spacing future input with the IN command.

STM n = adjust length of stems which extend above or below staff n.
        If n is larger than 32, all staves will be considered.

        Note that beams are NOT moved by this command.  Move beams to their
        proper positions and then use the AD command to adjust the stem
        lengths under beams.

STUD = adjust spacing of notes with alternating STems Up and Down.
        This causes the STEM position to be the basis of spacing instead
        of the note head position.  Use this feature with care when
        rhythms must line up with other parts.

ST n c1 c2 c3 =edit staff n, find up to 3 code nums. (See also E.HLP.)
           If n > 32, then all staves are searched for code numbers.
           If no code numbers are given, all items on staff may be edited.

           Add 1000 to 'n' to edit all staves BEGINNING with staff n.

Extended letter commands:

     These commands are shortcuts for creating various items.  They should
     normally be followed by 2 or 3 numbers (parameters 2, 3, 4).

         sub 3 45 14   will put "subito" on staff 3 at position 45,
                       vertical position 14.

SLUR    = slur, curve up
SLURD   = slur, curve down
SLURn   = tuplet bracket up, n = number
SLURDn  = tuplet bracket down, n = number
STA n   = staff lines at level n
STAC    = staccato dot
SUB     = subito
sf, sfz = sforzando

Each box represents a parameter that may be controlled by sliding the mouse
horizontally in the main screen area. Sliding the mouse to the right will
increase the value of the parameter. Sliding to the left will decrease the
parameter value. The left button will increment in small steps; the right
button will increment by larger steps. The increments will vary depending
on the nature of item being edited and the particular parameter involved.
(For example, if you are editing a note and click on box 4, P4, the vertical
position parameter will increment by full scale steps, whereas, box 8, 
the stem length parameter, will increment by much smaller units.)
The clicking on the '0' box will set the indicated parameter to 0.
