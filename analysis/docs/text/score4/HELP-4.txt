SCORE code numbers:

  Code 1. = Notes.               Code 10. = Numbers, rehearsal letters.
       2. = Rests.                    11. = User-added symbol library.
       3. = Clefs.                    12. = Circles, squares, guitar chords.
       4. = Lines, crescendo.         13. = (Reserved for future use.)
       5. = Slurs, brackets.          14. = Barlines.
       6. = Beams.                    15. = Insert PostScript code.
       7. = Trills, ottava, pedals.   16. = Text.
       8. = Staff lines.              17. = Key signatures.
       9. = Music symbol library.     18. = Meter.

 EDIT mode commands:                                                      8/12

    AB  = abort edit.                A = align after Set command.
    CN  = center.                   CR = set slur default curvature.
    CW  = center whole rests.       CX = copy and move to next.
    C n = copy, go edit item n.     CC = copy and continue.
    CD  = center dashes(in text). CM s = center nums., meter on barline.
    CV  = center slurs vertically and horizontally.
    DE  = delete.                  P n = show original value of parameter n.
    SZ  = see absolute size factor.  SZ n = set absolute size. 
    S   = set alignment position.    TP n = set tab fret position to >= n.
    X n (<esc>, <end>) = exit from edit mode, go edit item n.
    Z,ZZ = zoom 
    UND = undelete last deleted item. (Only before any edit changes.)

    L,R,U,D n = move item left, right, up, down.  (n is "sticky.")
       Arrow keys are same as L1, R1, U1, D1.
       <PgUp>=U4, <PgDn>=D4, <Tab>=R10, <shft><Tab>=L10.

    Type "INC n" to change arrow increment to the value of "n".
    <ctr>I returns increment to 1.

    -, +, (f2) = change direction to next item to edit.
    <alt>n = set parameter number for editing with up/down arrow keys.

 Text editing:                                                            9/12

    To edit text string type TX or "[" (starts at front of line)
    or "]" (starts at end of line).

       <home> = move cursor to front of line, <end> = move to end.

    CT n = center text at position n. (n is "sticky.")

    J n1, n2 = justify text in space from n1 to n2. (n1 and n2 are "sticky.")
    JR n = right justify to position n. (n is "sticky.")

    LS n = set vertical line spacing by scale steps.
            LSI = by inches, LSC = by centimeters, LSP = by points.

    PT = see current point size.      PT n = reset point size to n.

    RIP n = ripple n words (or -n) to line below (or above).
    RIPX n = ripple to newly created text line.

    RM n1,n2,n3 = set right margin to position n1 ("ragged right").
         n2 = number of lines to justify. n3 = set new vertical line spacing.
    RMJ = as above, but right side justified.

Alternate Keystrokes for windowing:   (Hold down <Alt> then press a key)

    <alt>C - CLOSE. Close graphics window to minimun size (Text window max.)
    <alt>D - DOWN.  Move bottom of text window DOWN 1 line (make it bigger).
    <alt>F - FULL.  Toggle FULL screen graphics on/off.
    <alt>M - MENU.  Toggle function key MENU on/off.
    <alt>O - OPEN.  Open graphics window to maximum size (Text window min.)
    <alt>S - SHOW.  Show entire page with current graphics window outlined.
    <alt>U - UP.    Move bottom of text window UP 1 line (make it smaller).

Keystrokes for text window and line editing:                             11/12

    <Home>      - Clear text window.
    <Lft Arrow> - Move text cursor left for line editing.
    <Rht Arrow> - Move text cursor right for line editing.
    <Ins>       - Toggle insert mode on/off for line editing.
    <Del>       - Delete character at current cursor location.
    <BackSpace> - Backup one space and delete character.
    <Ctrl>Q     - Regenerate last text line entered (must be first character).
        While in Edit Mode, ` (the key above <Tab>) does the same thing
        as <Ctrl>Q immediately.

Keystrokes for graphics window:   (Zoom, Pan, Page up/down, etc.)

    <End>        - Zoom to size 1 and display the bottom of the page. (Default)
      `          - Zoom to size 1 and display level of screen last active.
    <PgUp>       - Move 50% up the page.
    <PgDn>       - Move 50% down the page.
    <Up Arrow>   - Move 5% up the page.
    <Dn Arrow>   - Move 5% down the page.
    <Ctrl><PgUp> - Zoom in. Make graphics bigger. See less of the page.
    <Ctrl><PgDn> - Zoom out. Make graphics smaller. See more of the page.
    <Ctrl><Left> - Pan the page 10% left.
    <Ctrl><Rght> - Pan the page 10% right.

Mouse:

   Click any button on menu bar        - Activate normal function key.
   Click lft or rht button on an item  - Select item for editing.*
   Click middle button on screen edges - Shift screen image up/dn, lft/rht.**
   Click all 3 buttons                 - Zoom to size 1 (same as the ` key).


    * If item is moved while holding down right button or right button
      is pressed after moving with left button, a copy is made.

   ** After editing an item, the middle button may be used to directly
      select a new item.
