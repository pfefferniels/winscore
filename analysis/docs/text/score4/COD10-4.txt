  P5 may be used for numbers 0 to 999.  If P5 > 1000, then capital letters
  print.  (For rehearsal letters.)  P5 = 1001 = "A", P5 = 1002 = "B", etc.

  If 100 is added to P6's size value, the part extractor feature in the PAGE
  program will put the number (rehearsal number) in all player's parts.
  P6+200 makes all parts ignore the number.  (Use for score page nums., etc.)
  P6+300=use in all parts, but change to size factor to 1.


*
                                                                            2/3
  P7 = type font: = 0 = Times-Roman(on laser), Bodoni(on line printer)
                  = 1 = Times-Italic(on laser), Italic Bodoni(on lpt)
                  = 2 = primitive (stick letters), = 3 = always Bodoni
                  = 4 = always Italic Bodoni,      = 6 = Music number font
                  = 7 = Bodoni bold,  = 8 = Italic Bodoni bold
                  = 10 = Times-Bold(laser),  = 11 = Times-BoldItalic(laser)
                  P7 = 1000 to 1089 = laser fonts.  (1000-1032 built in.)


  P8 = 1 = circle around number; = 2 = box around number.

  (P9, P11, and P12 must all be used together.  They should rarely be used.)

  P10 = 1 adds 1 thickness to box or circle, = 2 adds 2, etc.

  P15 = horizontal offset of number from P3 position.

  ****************************
  CM = CenterMeter (& numbers).  This sets P3 and P15 to center number over a
  ****************************   nearby bar line. (But not with double meters.)

                                       (P9 = -1 does same as CM)

*
                                                                            3/3


  P16  Set P16=1 for a single-digit number to take part in the justifying
       process. This can also be used with a P15 offset.

       The main purpose for this is when fingering numbers must be placed
       to the left side of chord notes.
