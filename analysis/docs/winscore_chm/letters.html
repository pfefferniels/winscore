Index of Letter Commands

Letters for Command Mode.

    8va, 8ba (x y z) = octave higher, octave lower
    15ma (x y z) = 2 octaves higher
A _______________________________
   A = group alter
   AB abort, cancel edit changes 

   ACL (x y z) = "accel." (x=staff, y=horizontal position, z=vertical position, Code 9, P5=68)
   ACN (x y z) = accent, Code 9, P5 = 22
   ACNS (x y z) = accent over staccato, Code 9, P5 = 26
   ACT (x y z) = accent over tenuto, Code 9, P5 =112
   AD [staff #, n] = Adjust stem lengths of notes to match beam levels, see Code 1, Code 6.
   ADD, staff #, top meter #, bottom meter #, pickups, staves up. (add bar lines)

   ADF [staff #, n] = Adjust stems in the "French" manner
   ADObe (type fonts on screen)

   Align (after Set)

   ALT (x y z) = alto clef (ALTOM = mini clef), Code 3
   ARC (x y z) = "arco", Code 9, P5 = 67
   ARP (x y z) = vertical arpeggio wiggle, Code 4
       ARU  =  arpeggio, arrow up
       ARD  =  arpeggio, arrow down

   AST (x y z) = asterix, Code 9, P5 = 71
   ATM (x y z) = "a tempo", Code 9, P5 = 78
B _______________________________
   BAR (x y z) = barline (x=staff, y=horizontal position, z=staves up), Code 14
   BARn = barline, n = number of staves up
   BARBC (x y z) = brace
   BARBK (x y z) = bracket
   BARD (x y z) = double bar
   BARH (x y z) = heavy double bar
   BARL (x y z) = repeat bar, dots to left
   BARR (x y z) = repeat bar, dots to right
   BARRD (x y z) = double repeat bar, dots on both sides
   BAS (x y z) = bass clef (BASSM = mini clef), Code 3
   BEAM (x y z) = beam, Code 6
   BEAMn = beams, n = number of beams
   BEAT n = how many beats in line n

   BOT = move to bottom of page, left side

   BOTM = move to bottom of page, middle

   BOTR = move to bottom of page, right side

   BOX (x y z) = box, Code 12

   BZ = end edit, move to previous item with the same code number

C  _______________________________
   C = group copy
   CD n  center lyrics dashes on staff n

   CDA  center lyrics dashes on all staves

   CIR (x y z) = circle, Code 12
   CLE (x y z) = treble clef (CLEFM = mini clef), Code 3
   CLEFTA (x y z) = tablature clef. Code 3
   CM n = center meter, number, or bar over nearest bar on staff n
   CN (n) = Center item on note or rest

   CNL = center left end of slur at front of line (Code 5, Edit Mode) 
   CNR = center right end of slur at end of line (Code 5, Edit Mode) 

   CNX  Center beams on notes with different stem directions (Code 6, Edit Mode) 

   COM = combine alphabetically ordered files
   COMM (x y z) = common time - C, Code 18
   CRH (x y z) = crescendo hairpin, Code 4
   CR- = dashed hairpin, Code 4

   CRS (x y z) = "cresc.", Code 9, P5 = 63
   CRV = group adjustment of slur curvature, Code 5, P7
   CRVM  =  decrease curvature. (M = minus)
   CRVP  =  increase curvature. (P = plus)

   CS = copy complete system
   CT = cut -- for CUT/PASTE
   CT = center text  (Code 16, Edit Mode) 

   CUE = convert to cue-size notes/rests/beams

   CUT = cut time, alla breve, Code 18
   CV  =  center slur, set default vertical position and curvature, Code 5

   CW n = center all whole rests on staff n
   CWA = center all whole rests on all staves
D _______________________________
   DASH (x y z) = dashes (x=staff, y=horz. position, z=vertical), Code 4
   DCH (x y z) = decrescendo hairpin, Code 4
       DC- = dashed hairpin

   DCR (x y z) = "decres.", Code 9, P5 = 111
   DE = group delete
   DEC = DECombine several staves to separate files

   DEPL =  delete left side (verso) complete page

   DEPR =  delete right side ( recto) complete page

   DFLT = reset parameters to defaults

   DIM (x y z) = "dim.", Code 9, P5 = 64
   DNB (x y z) = down bow sign, Code 9, P5 = 28
   DOT (x y z) = dotted line, Code 4, P7 = -4

   DPY = export screen (display) to input for DRAW program
   DSHL  =  default dash length (or dot size) Code 4, P8
   DSHL-  =  shorten dashes
   DSHL+  =  lengthen dashes
   DSHS  =  default dash space (P9)
   DSHS-  =  shorten dash space
   DSHS+  =  lengthen dash space
E _______________________________
   ED x,y,z = edit items found near position x, staff y, code number z
   EDI = edit recreated input mode
   END1 (x y z) = 1st ending, Code 5
   END2 (x y z) = 2nd ending
   ENH = enharmonic shift of notes, Code 1

        ENHU = to upper note, ENHD = to lower note

   EQA, EQS - Equalize Staff spacing
   ESP (x y z) = "espr.", Code 9, P5 = 79
F _______________________________
   FER (x y z) = fermata, Code 9, P5 = 31
   FLI = flip notes, beams, slurs
   FLU = flip all up
   FLD = flip all down
   FLN = flip to normal up/down directions
   FH = display full height of image

   FNT  =  default type font for tuplet number. Code 5  (2 = Times-Italic)
   FNT n  =  font number = n. Code 5, P14

   FW = display full width of image

   f, ff, fff, fp (x y z) = forte, double forte, etc.
G _______________________________
   G name = get file "name"
   GLI (x y z) = "gliss.", Code 9, P5 = 72
   GM name = get more - add another file to screen

   GML file = get more and put file on left (verso) page

   GMR file = get more and put file on right (recto) page

   GMB  = get more, get next file BACK in sequence, put on verso position 

   GMN = get more, get next file in sequence, put on recto position 

   GP = get previous file

   GRA x = set gray scale value (in Edit mode)

   GUI (x y z) = guitar chord grid
H _______________________________
   H = see and adjust height of complete image on screen
   HAR (x y z) = harmonic sign, Code 9, P5 = 30
   HARP (x y z) = harp pedal sign, Code 7
   HO = when editing code 4, make horizantal line

   HS = height from the bottom line of staff 1 to top line of top staff
   HVW (x y z) = heavy wedge accent, Code 9, P5 = 36
I _______________________________
   I x = go into EDIT mode starting with Item x
   II = edit last item entered

   IN p2,p3,p4,p5 = starts the main SCORE input system (F2)
   INC n = change left/right arrow increment to n units
   INCH = change measurements to inches
   INV (x y z) = inverted mordant, Code 9, P5 = 35

   INVIS = invisible items On/Off (staves, bars, rests)
J _______________________________
   J = justify complete systems (see LJ)
   JR n = justify text to right, position n

   JT = justify text (lyrics) under music
K _______________________________
   KSIG (x y z) = key signature, 1 sharp, treble clef, Code 17
   KSIGvnw = key sig., v = + = sharps, - = flats, n = number,
   w = B = bass clef, A = alto, T = tenor
L _______________________________
   LAR  =  left arrow on/off, Code 4, P11 

    LAY = page layout

   LBR  =  left bracket on/off, Code 4, P11
   LBR-  =  shorten bracket (-.5)
   LBR+  =  lengthen bracket (+.5)
   LBRD  =  left bracket down

   LI = line up complete systems of music
   LIN (x y z) = horizontal line, Code 4
   LJ = line up and justify complete systems of music
   LJA = line up and justify all systems
   LOG (x y z) = SCORE logo, Code 9, P5 = 199, 299
   LOFF (P, M, n) = offset left end of Code 4, 5, 6, 7, P = +.5, M = -.5 

M _______________________________
   M = group move
   MA = create a macro command list
   MEN (x y z) = "meno", Code 9, P5 = 80
   MET = change to metric (centimeters) measurements
   METER (x y z) = meter -- defaults to 4/4, Code 18, P5,6
   METER34 = meter -- 3/4
   METER1216 = meter -- 12/16, etc.

   MID  =  set midpoint of slur.  P10 = 0 
   MIDL  =  move midpoint to left.
   MIDR  =  move midpoint to right.

   MID = move to middle of page, left side (not in Edit mode)

   MIDM = move to middle of page, middle

   MIDR = move to middle of page, right side

   MN = add measure numbers

   MOL (x y z) = "molto", Code 9, P5 = 73
   MOR (x y z) = mordant, Code 9, P5 = 34
   MSEE = See motive list 

   MS, MSX = move a system of staves to new staff numbers
   MT(x y z) = move a line of text (lyrics) and dashes up/down

   MUD = move group of items up/down by scale steps

   mf, mp (x y z) = mezzo forte, mezzo piano, Code 9
   MX = repeated moves

N _______________________________
   NX = get next file in alphabetical sequence
   NB = get previous file in sequence (NB = next back)
   NMO = turn Off/On display staff numbers

   NOT (x y z) = quarter note, stem up
   NOTED = quarter note, stem down
   NOTEF = quarter note with flat, stem up
   NOTEDF = quarter note with flat, stem down
   NOTES = quarter note with sharp, stem up
   NOTEN = quarter note with natural, stem up -- etc.
   NUM (x y z) = number (defaults to 0, set P5 for other numbers), Code 10

   NUML  =  move number in bracket to left. Code 5, P17 
   NUMR  =  move number in bracket to right.
   NUMH0  =  default horizontal number position. P17 = 0
   NUMU  =  move number in bracket up.  P18 
   NUMD  =  move number in bracket down.
   NUMV0  =  default vertical number position. P18 = 0
   NZ = end edit, move to next item with the same code number
O _______________________________
   OH = reorder all items in horizontal (left-to-right) order
   OS = reorder all items by staff number (left-to-right on each staff)
   OT = reorder text items only (Code16, by staff, starting with highest staff)
   OSR = reorder all items by staff number in reverse order

P _______________________________
   PATH \x = Change path to disk directory \x  

   PATHX  get the Path List.

   PED (x y z) = "Ped.", Code 9, P5 = 70
   PEDA (x y z) = graphic piano pedals
   PEDB, PEDC (x y z) = piano pedal lines with wedge
   PER (x y z) = percussion clef, Code 3

   PG n = get back parameter n value saved with PS n
   PGR = move complete page from left (verso) to right (recto)

   PL = play sound (F5)
   PM = prints parameter list of all items to the screen
   PMX = creates an ASCII file containing all parameter data
   POS (x y z) = read in PostScript .EPS file (Code 15)
   PR = bring up printing menu (F6)
   PREF = see and edit current preference setup
   PS n = save value of parameter n (retrieve it with PG n)

   PT = see point point size of text and reset

   PTS = extract individual parts frm full score

   p, pp, ppp (x y z) = piano, etc., Code 9
   piu = "piu", Code 9, P5 = 81
   piz = "pizz.", Code 9, P5 = 66
   plu = "+", Code 9, P5 = 38
   poc = "poco", Code 9, P5 = 86
R _______________________________
   ral (x y z) = "rall."c Code 9, P5 = 113
   rit (x y z) = "rit.", Code 9, P5 = 65
   RAR  =  right arrow on/off , Code 4, P12 
   RBR-  =  shorten right bracket (-.5), Code 4, P12
   RBR+  =  lengthen right bracket (+.5)
   RBRD  =  right bracket down

   REad name = read in MACRO command file "name"

   REDO = redo action after UNDO was typed
   REP n  repeat reading a macro file n times

   REST (x y z) = quarter rest
   RESTOre  = restore item lost when X (exit from edit mode) was typed instead of C (copy)

   RGB = bring up color chooser
   RIP, RIPX = ripple bars of music from one line of music to next or previous
   ROFF (P, M, n) = offset right end of Code 4, 5, 6, 7  P = +.5, M = -.5  

   RNUM x y = renumber Item x as Item number y
   ROT  =  in Edit mode, rotate to normal position
   ROT+  =  rotation clockwise
   ROT-  =  rotation counter-clockwise

   RS (name) = restart SCORE (and GET file "name")
   RSM (name) = restart with same name
S _______________________________
   SA name = save all data on screen in file "name" (binary save)
   SAW  =  saw tooth line, Code 4, P7 = -3
   SAWX  =  heavy saw tooth line (P11)

   SM = save data with same name as current name (at top of screen)
   SNX = save with next name alphabetically up from current name
   SNB = save with next BACK name alphabetically from current name
   SC n = put up spacing scale above staff n
   SCC n = put up spacing scale in centimeters above staff n
   SCI n = put up spacing scale in inches above staff n
   SCP n = put up spacing scale in points above staff n
   SCV  = put up vertical scale in inches
   SCVC  = put up vertical scale in centimeters
   SCX = erase the spacing scale
   SEP = command to assist in separating parts on a multi-voice staff

   Set - Align
   SLDSH  =  dashes. Code 5, P11 = 1
   SLDT  =  dots. Code 5, P11 = -1
   SLHL  =  half slur left. P12 = 1
   SLHR  =  half slur right. P12 = 2

   SLTR  =  triplet slur. P16 = 3
   SLUR (x y z) = slur, curve up, Code 5
   SLURD = slur, curve down
   SLURn = tuplet bracket up, with number n
   SLURDn = tuplet bracket down, with number n
   SP n = set staff n as the basis for spacing input with the IN command

   SPL n1,n2 . . .  split beams into various groups

   SPD+/- = increase/decrease spread of hairpins
   ST n c1 c2 c3 = edit items on staff n - find up to 3 code numbers
   STX c1 c2 c3 = edit listed code numbers on all staves
   STA (x y z) = staff lines (at staff level x, horz. y, vert. z), Code 8
   STAC (x y z) = staccato dot, Code 9, P5 = 24
   STM = adjust length of stems which extend above or below staff
   STSP = set space between staves

   STUD = adjust spacing of notes with alternating stems up, stems down
   SUB (x y z) = "subito", Code 9, P5 = 85
   SZ = see absolute size of item and reset

    sf, sfz (x y z) = sforzando, Code 9, P5 = 61, 62
T _______________________________
  T p1 p2 p3 p4 p5 p6 = enter text using the given parameters
  TAB = create guitar tablature from existing line of music
  TBX = put box on text - Code 12

  TEN (x y z) = tenor clef (TENORM = mini clef), Code 3
  TENS (x y z) = tenuto/staccato, Code 9, P5 = 27
  TENU (x y z) = tenuto, Code 9, P5 = 23 
  TC = enter lyrics text syllables to be centered on notes
  TCX = enter lyrics syllables centered, punctuation ignored
  THK  =  default line thickness, Code 4
  THK+  =  thicken line, Code 4, P10

  THK  =  default slur thickness. Code 5 (set in Preference file, P13 = 0)
  THK n =  set beam thickness. Code 6 (THK alone = default)
  THKM  =  decrease slur thickness. (P13)
  THKP  =  increase slur thickness. (P13)

  TIE (x y z) = tie, curve up (slur between notes)
  TIED = tie, curve down
  TOP = move to top of page, left side

  TOPM = move to top of page, middle

  TOPR = move to top of page, right side

  TPL, TPLN =  Top Left display when page is read in, Top Left No.

  TRE (x y z) = treble clef (TREBM = mini clef), Code 3

  TR n = transpose staff n
  TREM (x y z) = tremolo beam, note stem up
  TREMD = tremolo beam, note stem down
  TREMn, TREMDn = n = number of tremolo beams
  TRP  =  change duple rhythm to triple, Code 1, 2, P7 

  TRP  =  triplet bracket. Code 5  (P8 = 3) 

  TRI  =  make triangle. Code 5, P9 = 99

  TT = allows entry of several lines of text
  TTR = allows the read-in of an external file as text input
  TUR (x y z) = turn (ornament), Code 9, P5 = 75
  TYPE name = type the contents of disk file "name" to screen
  TXD char. = change the text divider to any given character.
U _______________________________
  UND = undelete last item deleted
  UNDO = undo last group edit or GM command
V _______________________________ 0

  VC  vertical centering between staff and staff above

  VCB  vertical centering between staff and staff below

  VCS  vertical centering of text in front of staff

  VE = when editing code 4, make vertical line

  VER = SCORE version number and program serial number  

  VJ = vertical justify
W _______________________________
  WED (x y z) = inverted wedge accent, Code 9, P5 = 21
  WEDS (x y z) = wedge/staccato, Code 9, P5 = 25

  WIG  =  heavy wavy line (wiggle), Code 4, P7

X ________________________________
  X  exit from edit mode or group edit

  XX  exit from edit and save item for paste (copy)

  XOFF = zero offsets of many items

Z ________________________________
  Z n = zoom screen image to n times the normal size
  _______________________________

  <left arrow> = move window to left
  <right arrow> = move window to right
  <up arrow> = move window up
  <down arrow> = move window down
  <page up>, <page down> = move window up/down
  <home> = move window left, <end> = move window right

  <ctrl> <page up>, <page down> = image size bigger/smaller

 

While in Edit Mode:

  <ctrl><left arrow> = move window to left
  <ctrl><right arrow> = move window to right
  <ctrl><up arrow> = move window up
  <ctrl><down arrow> = move window down
  <ctrl><page up>, <page down> = image size bigger/smaller
