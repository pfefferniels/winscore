P5 may be used for numbers from -999.999 to 999.999. 

     A minus sign may precede the number (but nothing else!)
     For rehearsal letters use P5 = 1001 = "A", P5 = 1002 = "B", etc.
     For lower case letters use P5 = 2001 = "a", etc.

     For numbers greater than 999 and composite letters see P18

 

P6  = size factor.

     P6 = size + 100 = the number will be used by ALL extracted parts.
     P6 = size + 200 = the number will NOT be used by ANY other extracted parts.

     P6 = size + 300 = use this number in all parts and change size to 1.

 

   The size of the number is always dependent on the size of the staff to which the number is attached.

 

P7 = type font.

     P7 = 0 = Times-Roman, 1 = Times-Italic, 2 = Helvetica,  

             3 = NewCenturySchlbk-Roman, 4 = NewCenturySchlbk-Italic,

             5 = Helvetica-Oblique, 6 = music font numbers (for meter, etc.),
             7 =  NewCenturySchlbk-Bold, 8 = NewCenturySchlbk-BoldItalic,

             9 =  Times-Bold, 10 = Times-BoldItalic.

            For any other available font, set P7 = 1000 + font# (see Code 16).

 

P8 = 1 = circle around number, = 2 = box.

 

P10  sets thickness of box/circle

 

P11  horizontal size of box/circle (Use negative number to decrease size.)

 

P12  vertical size of box/circle

 

P13  vertical displacement of box/circle (Positive or negative number.)

 

P14  horizontal displacement of box/circle (Positive or negative number.)


P15  horizontal displacement of number (including box/circle if present.)

 

P17  letter after number

        If P5 = 0 to 999, P17 can create a following letter.

              P17 = 1 to 26 = A to Z

              P17 = 101 to 126 = a to z

                          For example: P5 = 97, P17 = 102 will display 97b, etc.
        This feature might be used for measure numbers with 1st and 2nd endings, i.e. 23a, 23b.

 

P18  Extended rehearsal numbers/letters
        For numbers greater than  999 -- P18 = 1000 to 9999 (P5 is ignored.)
        For various extended rehearsal letters -- P5 sets first letter ( = 1001 = A, etc.)

              If P18 has only 2 digits, that number will appear after the letter given by P5.

                                                     P18 = 1 to 99 (+P5)

                                                                       P5 = 1001, P18 = 1 = A1 

                                                                       P5 = 1001, P18 = 2 = A2  etc.

                                                                       P5 = 1002, P18 = 12 = B12  etc.

              If P18 has 4 digits, xxyy, xx creates the 1st following letter and yy a 3rd letter.

                                                     P18 = 0100 to 2600 (+P5)

                                                                       P5 = 1001, P18 = 0100 = AA

                                                                       P5 = 1002, P18 = 0300 = BC etc.

                                                     P18 = 0101 to 2626 (+P5)
                                                                       P5 = 1001, P18 = 0101 = AAA

                                                                       P5 = 1003, P18 = 0226 = CBZ  etc.

                                                     P18 = -0100, etc. Aa, Bcc, etc.
                                                                       P5 = 1004, P18 = -0100 = Da

                                                                       P5 = 2003, P18 = -0500 = ce

                                                                       P5 = 2026, p18 = -2626 = zzz  etc.   

 

P19  rotation

 

P20  spread digits (0 or 1 = no spread, best is 1.1 or 1.15)

P25 layer number. 

           See Color Control.

 

P26 color/gray value. 

           See Color Control.

-------------- Shortcut Letter Commands while editing Numbers ---------------
PL n  =  plus n -- add n to current P5.

MI n  =  minus n -- subtract n from current P5.

UP  =  change to upper case A.
LW or LO  = change to lower case a.
NU n = change to number n.
SPR  =  spread the digits (sometimes needed with music_font numbers). (P20)

SPRX  =  no spread. (P20 = 0)
FNT n  =  change to font number n. (P7)

ROT+, ROT- = rotate number +/- 10 degrees. (P19) (Box/circle will not rotate.)

ROT0 = no rotation. (P19 = 0)

SZ+, SZ- = increase/decrease number size. (P6) (Box/circle will not change.)

SZ0 = basic size. (P6 = 0)

CN n  =  center on nearest note/rest on staff n. (P3) 

CM  =  center on nearest measure line whose top point is on number's staff. (P3, P15)

 

ALPTS  =  put number in ALL extracted parts. (P6 + 100)

NOPTS  =  put number in NO extracted parts. (P6 + 200)

NORM  =  normal, put number in no other parts.

 

BXC  =  if repeated -- change to circle, then box, then nothing. (P8 = 1, 2, 0)
BSD  =  default size and shape of box/circle.

THK  =  increase line thickness of  box/circle. (P10)

THK0  =  minimum line thickness of  box/circle. (P10 = 0)

BXVP  =  vertical size plus of box/circle in relation to number. (P12)

BXVM  =  vertical size minus of box/circle in relation to number. (P12)

BXHP  =  horizontal size plus of box/circle in relation to number. (P11)

BXHM  =  horizontal size minus of box/circle in relation to number. (P11)

BXU  =  vertical position up of box/circle in relation to number. (P13)

BXD  =  vertical position down of box/circle in relation to number. (P13)

BXR  =  horizontal position right of box/circle in relation to number. (P14)

BXL  =  horizontal position left of box/circle in relation to number. (P14)

 

>>> Offsets
OFM  =  offset minus, moves item .5 step to left. Moves number AND box/circle. (P15)
OFP  =  offset plus, moves item .5 step to right.
NOF  =  no offset of item -- P15 = 0.
