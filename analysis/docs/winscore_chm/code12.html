      Jump to Letter Commands

      Jump to Function Key Setup


P5  box/circle.

    

For putting boxes on numbers see Code 10 - P8.

For putting boxes on text (TBX) see Code 16.

 

For boxes with dashed lines P5 = 3.

The number of dashes in each line will depend on the box size and the dash size.

        

Please note that while the varying line thicknesses will print properly, they will display only as one added thickness.


P6  horizontal size in scale steps. (default P6 = 10)

    

 

P7  vertical size in scale steps. (default P7 = 10)

      If P7 is left at zero it takes the value given in P6.

 

    

 

P8  line thickness.

    


P9  rotation.   

    


P10  skewed rectangles.
    

 

P10, P11  partial circles (arcs).

    


P12  change circle into polygon, dashes.

    

    


P13  fill in shape.
    


P15  horizontal displacement.

P25 layer number. 

           See Color Control.

 

P26 color/gray value. 

           See Color Control.
